# 🚁 Disaster Rescue & Surveillance System

### VIT Vellore | Basic Multidisciplinary Project (MDP) | 2026–2027

A Python-based intelligence and decision-making system developed as part of a multidisciplinary project focused on disaster rescue and surveillance using a ground robot and an aerial drone.

The software focuses on collecting telemetry and sensor information, checking data quality, assessing environmental conditions and generating priority classifications to support informed decision-making.

**Project Status:** 🟡 In Progress — Prototype Development & Testing

---

## 📌 Project Overview

During disaster situations, entering damaged or hazardous environments can put rescue personnel at risk.

This project explores the use of a surveillance drone and a ground robot to collect information from such environments.

The software component processes incoming data and evaluates the available information before producing an assessment.

My primary contribution focuses on the **Python-based data processing, sensor intelligence and decision-making layer**.

---

## ⚙️ System Architecture

The software is organized into two primary components.

### 1. Drone Telemetry

The drone module uses MAVLink communication through `pymavlink` to receive telemetry information.

Data handled includes:

* Roll, pitch and yaw.
* GPS latitude and longitude.
* Relative altitude.
* Battery voltage and remaining percentage.
* Telemetry reception timestamps.

The system also performs data availability, validity and freshness checks.

### 2. Sensor Intelligence & Decision Pipeline

The intelligence module processes incoming sensor packets and evaluates environmental conditions.

The current implementation includes:

| Component           | Responsibility                                            |
| ------------------- | --------------------------------------------------------- |
| Sensor Packet       | Creates and validates incoming sensor data structures.    |
| Data Validator      | Checks availability, validity and freshness of readings.  |
| Sensor Synchronizer | Groups sensor readings based on timestamp tolerance.      |
| Sensor Fusion       | Evaluates gas levels, temperature and nearby obstacles.   |
| Processing Pipeline | Combines validated sensor information into an assessment. |
| Priority Model      | Generates LOW, MEDIUM or HIGH priority classifications.   |
| UDP Receiver        | Receives and processes sensor packets over UDP.           |

### Processing Flow

## 🧠 Decision-Making Logic

The intelligence pipeline evaluates three primary sensor inputs:

* **Gas Level:** Identifies readings exceeding configured thresholds.
* **Temperature:** Identifies unusually high temperature readings.
* **Distance:** Identifies nearby obstacles based on configured thresholds.

Before using readings, the pipeline checks whether they are:

* Available.
* Within acceptable validity ranges.
* Associated with valid timestamps.
* Fresh enough to be considered usable.

The system then generates an assessment containing hazard information, obstacle information and sensor data quality.

### Priority Classification

The project also includes a Decision Tree classifier that produces three priority categories:

| Classification | Description                       |
| -------------- | --------------------------------- |
| LOW            | Lower-priority assessment.        |
| MEDIUM         | Intermediate-priority assessment. |
| HIGH           | Higher-priority assessment.       |

The current model is trained using synthetic data generated by the project’s training script.

**Important:** The classifier is an experimental prototype and its predictions are advisory. It has not been validated against real disaster-site datasets.

## 🚀 Running the Software

### Prerequisites

* Python installed.
* pip package manager.
* Git (optional, for cloning the repository).

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
cd vit-mdp-rescue-system
```

### 2. Install dependencies

```bash
pip install pymavlink scikit-learn joblib pytest
```

### 3. Run the sensor intelligence pipeline

```bash
python -m intelligence.stream_processor
```

This starts the JSON-based sensor processing interface.

### 4. Run the UDP receiver

Open a terminal:

```bash
python -m intelligence.udp_receiver
```

Open another terminal:

```bash
python -m tests.send_udp_test_packet
```

The second command sends a simulated sensor packet to the local UDP receiver.

### 5. Run automated tests

```bash
python -m pytest -q
```

### 6. Run drone telemetry

The drone telemetry module expects a MAVLink connection at:

```text
udpin:127.0.0.1:14551
```

A compatible MAVLink telemetry source must be available before running the live telemetry module.
